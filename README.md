# ❤️ Heart Disease Prediction System

The Heart Disease Prediction System is a machine learning web application that predicts the risk of heart disease using patient health data.

Key features used for prediction include age, gender, blood pressure, cholesterol level, heart rate, chest pain type, ECG results, and other medical indicators.

The project involved:

* Data collection and exploration
* Data cleaning and preprocessing
* Training and testing a machine learning model
* Saving the model using Pickle
* Building a Streamlit web application

Users can enter patient information and receive instant prediction results through an interactive dashboard.

Technologies used include Python, Pandas, NumPy, Scikit-learn, Streamlit, and Pickle.

The application provides:

* Real-time predictions
* User-friendly interface
* Input validation
* Responsive design

This project demonstrates the application of machine learning in healthcare and supports early detection of heart disease risk.
